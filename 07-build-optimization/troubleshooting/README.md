# Build Optimization — Troubleshooting Journal

For every failure, record:

1. **Symptom:** What failed?
2. **Environment:** OS, Docker version, and relevant configuration.
3. **Evidence:** Logs, command output, exit codes, and container state.
4. **Hypotheses:** What could explain the failure?
5. **Investigation:** Which tests eliminated each hypothesis?
6. **Root cause:** What actually caused the problem?
7. **Fix:** What changed?
8. **Verification:** How was recovery confirmed?
9. **Prevention:** How can this failure be avoided in the future?
